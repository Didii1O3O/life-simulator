## ✨ 项目介绍
一个轻量的人生选择模拟器。
每一次选择都会改变你的人生属性，体验不一样的人生故事，整体为迪士尼治愈卡通美术风格。
- ✅ 完全前端静态实现，**不需要后端服务器**
- ✅ 电脑/手机浏览器都可以打开游玩
- ✅ 不同选择触发不同剧情走向与结局

## 🛠️ 技术栈
- HTML + CSS + JavaScript
- GitHub Pages 部署静态网页
